# XKV

这是一个使用C++开发的高性能的（至少希望上的）key-value数据库，使用IO多路复用存取、模板、单线程与一些自定义数据结构等机制以期更优秀的表现。

简言之，就是<del>抄的</del>致敬的Redis，理论上没有（可能有？）任何的先进之处，除了帮笔者进行一个C++习的学。

### 开发中或已部分实现

- 基本架构
- 数据结构
  - 哈希表与其渐进式rehash
- 网络模型
  - IO多路复用的`kqueue`和`select`版本
  - 简化版的应用层协议

## 使用

虽然本项目似乎不太有使用的需要，但若你只是想体验一下或仅出于好玩（因为笔者也很喜欢捣鼓），可以编译`xkv_test`的静态库目标后，链接这样的文件即可启动服务。配置需要在config.hpp中修改，部分配置项希望在编译前就已编码。

```cpp
#include <core/core.hpp>

int main() {
    xkv::core{}.loop();
}
```

目前仅支持一个哈希表与set、get、remove和cas操作，socket请求如下：
```
s key value
g key
c key value new_value
```
s、g、r、c为操作选项，除此之外每个字符串开头需要设置长度，并用`\r`分隔，命令结尾`\r\r`结束，编码如：
```
s\r3key\r5value\r\r
```
